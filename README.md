# 🌱 FarmDay – 농산물 직거래 & 시세 기반 커머스 플랫폼

FarmDay는 **농산물 시세 정보 + 직거래 + 공동구매**를 결합한  
생산자와 소비자를 직접 연결하는 웹 기반 커머스 플랫폼입니다.

소비자는 합리적인 가격으로 신선한 농산물을 구매할 수 있고,  
생산자는 중간 유통 없이 상품을 판매할 수 있도록 설계되었습니다.

---

## 📌 프로젝트 개요

- **프로젝트명**: FarmDay
- **개발 형태**: 팀 프로젝트
- **개발 기간**: 2025.11 ~ 2025.12
- **담당 역할**
  - 백엔드 핵심 도메인 구현
  - 관리자 페이지 전체 기능 구현
  - 결제 시스템(Toss Payments) 연동
  - 생산자 / 상품 / 주문 / 통계 기능 개발

---

## 🛠 기술 스택

### Backend
- Java 17
- Spring Boot
- Spring Security
- JWT 인증
- MyBatis
- Oracle XE
- Scheduler
- AWS S3

### Frontend
- React (Vite)
- Styled-components
- Axios
- Recharts / Chart.js
- SweetAlert2

### External API
- KAMIS 농산물 시세 API
- Toss Payments API
- OpenAI API
- Daum 주소 검색 API
